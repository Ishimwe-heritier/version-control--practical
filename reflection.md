# Final Reflection

Version control is important because it helps developers track changes in a project and work together without overwriting each other's work. The most difficult step was understanding the branching and pull request process, but it became easier after practice. Branches are useful because they allow developers to work on features separately, and pull requests help review changes before merging them into the main project.
